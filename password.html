    Security tips

    • Use a different password for every account. If one site is breached, attackers try the leaked password elsewhere.
    • Use a password manager. It can create and remember long, unique passwords so you only memorise one strong main password.
    • Turn on multi-factor authentication (MFA). Even if a password leaks, a second factor makes it much harder to sign in. Passkeys or security keys are the most phishing-resistant option.
    • Longer is better than clever. A long random passphrase is usually stronger and easier to type than a short string with a few symbols.
    • Do not share passwords by email or chat, and be careful with links that ask you to sign in.

    This tool only estimates guessability. It cannot know whether a password has already appeared in a data breach, and it does not recognise every dictionary word, name or personal detail (such as a birthday), which attackers try early.
