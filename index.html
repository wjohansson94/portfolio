Password checker & generator

Password strength checker and secure generator, all in your browser.

  • HTML
  • CSS
  • JavaScript
  • Web Crypto API
What I learned

What I learned: why generators should use crypto.getRandomValues instead of Math.random, how entropy (length times the size of the character pool) gives a rough strength estimate, and how to copy to the clipboard with a fallback.

Challenge: picking random characters fairly (a plain modulo favours some values, so I used rejection sampling) and writing pattern checks that do not count the same characters twice. The strength result is only an estimate.

Word guess game

A five-letter word guessing game with six attempts and saved stats.

  • HTML
  • CSS
  • JavaScript
  • localStorage
What I learned

What I learned: splitting game logic into small pure functions (scoring a guess, validating saved stats) that I could test in Node, building the board and keyboard with createElement, and making a game usable with both keyboard and screen readers through aria-labels and a live status message.

Challenge: marking repeated letters correctly (a letter can only be yellow as many times as it is still unused in the answer) and stopping the physical Enter key from also pressing a focused on-screen button. The word lists are small, so some real words are rejected.

Pomodoro timer

A focus and break timer with a progress ring and daily focus totals.

  • HTML
  • CSS
  • JavaScript
  • SVG
What I learned

What I learned: calculating the time left from a stored end timestamp instead of counting ticks, drawing a progress ring with an SVG circle and stroke-dashoffset, and keeping the logic in small pure functions that I could test in Node. I also practised validating saved settings and optional features (sound and notifications) that only start after a click.

Challenge: browsers slow down timers in background tabs, so a tick counter drifts. Using Date.now and recalculating when the tab becomes visible fixed it. Deciding when to announce changes to screen readers was also tricky: only mode changes are announced, not every second.

Expense tracker

Add expenses, see the total and a chart of spending per category. Written by hand in VS Code.

  • HTML
  • CSS
  • JavaScript
  • Chart.js
What I learned

What I learned: this one I wrote myself, as a beginner. I practised saving data in localStorage, using reduce to add up totals and filter to delete an item, building list items with textContent, and drawing a doughnut chart with my first library, Chart.js. I also used a labelled form, native input validation and a button label for each Delete.

Challenge: getting the chart to update after every change and to follow the light and dark theme. Chart.js draws on a canvas, so the legend colour has to be set again when the theme changes. The library is loaded from the jsdelivr CDN, so the chart needs an internet connection.
