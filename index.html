Password checker & generator

Password strength checker and secure generator, all in your browser.

  • HTML
  • CSS
  • JavaScript
  • Web Crypto API
What I understood

What I understood: why a generator should use crypto.getRandomValues instead of Math.random, how entropy (length times the size of the character pool) gives a rough strength estimate, and how copying to the clipboard has a fallback.

What was tricky to understand: picking random characters fairly (a plain modulo favours some values, so the code uses rejection sampling) and pattern checks that do not count the same characters twice. The strength result is only an estimate.

Built with AI

Pomodoro timer

A focus and break timer with a progress ring and daily focus totals.

  • HTML
  • CSS
  • JavaScript
  • SVG
What I understood

What I understood: how the time left is calculated from a stored end timestamp instead of counting ticks, how a progress ring is drawn with an SVG circle and stroke-dashoffset, and how the logic is kept in small pure functions that can be tested in Node. Saved settings are validated, and sound and notifications only start after a click.

What was tricky to understand: browsers slow down timers in background tabs, so a tick counter drifts. Using Date.now and recalculating when the tab becomes visible avoids that. Deciding when to announce changes to screen readers was also tricky: only mode changes are announced, not every second.
